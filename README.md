# Python 核心语法与空间数据分析 · 交互式课程

面向零基础的 Python 入门与时空数据分析课程，配套讲义和示例代码。

**在线学习：<https://xiangyu-ge.github.io/python-course/>**

> 课程是一个**单文件**网页，不依赖服务器、不请求任何外部资源。
> 下载 `index.html` 后双击也能直接在浏览器里打开、完全离线使用。

## 目录

| 文件 | 说明 |
| --- | --- |
| `index.html` | 交互式课程本体（32 幕）。在浏览器里直接运行 Python 代码、逐行观察执行过程、做题核验。 |
| `Python核心语法与时空数据分析_讲义.md` | 配套讲义全文（Markdown）。 |
| `dataset.py` | 课程用到的示例数据集（可独立运行）。 |
| `minialgo.py` | 课程里的迷你算法示例（可独立运行）。 |

## 课程内容

变量与容器、流程控制、函数、面向对象、常用标准库，再到数据统计、空间分析与时空分析。
每一幕都配一个可运行的小例子和几道检测题。

## 本地使用

```bash
# 方式一：直接双击 index.html

# 方式二：起一个本地服务器（可选）
python -m http.server 8000
# 然后打开 http://localhost:8000/
```
